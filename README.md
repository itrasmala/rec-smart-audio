# REC Smart Audio
### نظام الإذاعة الداخلية والأذان الذكي — رسملة الطاقة للمقاولات

يشغّل **الأذان تلقائيًا** و**الإعلانات المجدولة والفورية** على سماعات ممرات المبنى، وتتحكم به من الجوال أو الكمبيوتر من داخل الشركة أو خارجها. يستمر الأذان في وقته حتى لو انقطع الإنترنت أو أُغلق المتصفح أو أُعيد تشغيل الجهاز.

---

## التشغيل على كمبيوتر واحد (بدون سيرفر) — الطريقة الموصى بها

كل شيء يعمل على **كمبيوتر Windows الموصول بالسماعات**: لوحة التحكم، وقاعدة البيانات، وتشغيل الصوت. تفتح اللوحة من نفس الكمبيوتر أو من جوالك على نفس شبكة الشركة.

1. **اقرن سماعة البلوتوث** بالكمبيوتر من إعدادات Windows، كما تقرن أي سماعة.
2. افتح **PowerShell** والصق هذا الأمر، ثم اضغط Enter، ووافق على نافذة صلاحيات المسؤول:
   ```powershell
   irm https://raw.githubusercontent.com/itrasmala/rec-smart-audio/main/install-windows.ps1 | iex
   ```
3. بعد اكتمال التثبيت (دقائق قليلة) تفتح لوحة التحكم تلقائيًا. أدخل **رمز الإعداد** الظاهر في نافذة PowerShell، ثم أنشئ حساب المدير.

ماذا يفعل الأمر:
- ينزّل حزمة جاهزة فيها كل ما يلزم، ولا يحتاج تثبيت Node.js أو قاعدة بيانات. يثبّت Python تلقائيًا إن لم يكن موجودًا.
- يسجّل خدمتين تعملان مع تشغيل الكمبيوتر وتعيدان نفسيهما عند أي توقف، دون أن يفتح أحد البرنامج.
- يربط سماعات هذا الكمبيوتر باللوحة تلقائيًا، ويضع اختصار **REC Smart Audio** على سطح المكتب.
- يعرض لك رابطًا مثل `http://192.168.1.20:4000` لفتح اللوحة من الجوال داخل الشبكة.

**التحديث:** شغّل نفس الأمر مرة أخرى، وبياناتك تبقى كما هي.
**الإزالة:** `C:\REC-Smart-Audio\uninstall-windows.ps1` من PowerShell كمسؤول.

> **من خارج الشركة؟** في هذا الوضع اللوحة متاحة داخل الشبكة فقط. للوصول من الخارج استخدم VPN الشركة، أو انتقل لوضع الخادم السحابي أدناه.

## (اختياري) التشغيل بخادم سحابي للوصول من أي مكان

### 1) الخادم — أمر واحد
على أي خادم سحابي **Ubuntu** (مثلًا 2 vCPU و 2GB RAM):

```bash
curl -fsSL https://raw.githubusercontent.com/itrasmala/rec-smart-audio/main/install.sh | sudo bash
```

يعرض لك في النهاية **رابط لوحة التحكم** (أو رابطًا مجانيًا مثل `https://203-0-113-10.sslip.io` إن لم يكن لديك نطاق) و**رمز الإعداد**.

### 2) حساب المدير — من المتصفح
افتح الرابط، وأدخل رمز الإعداد، وأنشئ حساب مدير النظام.

### 3) جهاز السماعات — أمر واحد
في لوحة التحكم: **الأجهزة والسماعات ← إضافة جهاز**، ثم الصق الأمر الجاهز في PowerShell على الكمبيوتر الموصول بالسماعات.

## ما الذي تحصل عليه

| | |
|---|---|
| **الأذان** | أم القرى (الرياض افتراضيًا)، ملف وصوت لكل صلاة، تأخير بالدقائق، وقت ثابت، تعطيل صلاة، مطابقة التقويم الرسمي باستيراد CSV |
| **الإعلانات** | يومي / أسبوعي / مرة واحدة / نسبةً لوقت صلاة، تاريخ بداية ونهاية، إيقاف مؤقت |
| **الأولوية** | الأذان ← الطوارئ ← الإعلانات ← العامة؛ صوت واحد في كل لحظة؛ الأذان يقطع أي صوت |
| **الاستمرارية** | الجدولة تعمل محليًا على جهاز السماعات دون إنترنت، وتُعاد تلقائيًا بعد إعادة التشغيل، دون تكرار الأذان |
| **الصلاحيات** | مدير النظام، مسؤول الصوتيات، مشاهد — وسجل لكل عملية |
| **الواجهة** | عربية RTL مع الإنجليزية، ليلي ونهاري، جوال وكمبيوتر، تحديث مباشر |
| **الأمان** | HTTPS، لا منافذ مفتوحة في الداتا سنتر (الجهاز يتصل للخارج فقط)، رمز خاص لكل جهاز قابل للإلغاء |

## الربط بالسماعات
- **سلكي (موصى به):** وصّل مخرج AUX أو كرت صوت USB من الجهاز إلى مضخم سماعات الممرات.
- **بلوتوث:** أقرن السماعة من إعدادات Windows أو Linux أولًا، ثم اخترها في لوحة التحكم. لا يمكن إدارة البلوتوث من المتصفح مباشرة.

التفاصيل في [docs/AUDIO_SETUP.md](docs/AUDIO_SETUP.md).

## قبل التشغيل الفعلي
طابق أوقات الصلاة مع تقويم أم القرى الرسمي من **أوقات الصلاة ← مطابقة تقويم أم القرى**، وارفع ملفات الأذان الخاصة بالمؤسسة. القائمة كاملة في [docs/GO_LIVE.md](docs/GO_LIVE.md).

## للمطورين

| الجزء | المجلد | التقنيات |
|---|---|---|
| لوحة التحكم | [`web/`](web) | Next.js 16، TypeScript، Tailwind CSS 4 |
| الخادم | [`server/`](server) | Node.js 22، Fastify 5، Prisma 7، PostgreSQL 16، WebSocket |
| جهاز التشغيل | [`agent/`](agent) | Python 3.10+، asyncio، pygame/SDL2، SQLite، Windows Service / systemd |

```bash
# بيئة تطوير محلية (Node 22، PostgreSQL، Python 3.10+)
cd server && npm install && DB_DIR=./data/db npm run dev   # قاعدة بيانات مدمجة، لا حاجة لـ PostgreSQL
cd web && npm install && npm run dev                    # http://localhost:3000
# أول زيارة تطلب رمز الإعداد: تجده في سجل الخادم
```

**الاختبارات:** `cd server && npm test` (62 اختبارًا، وتعمل أيضًا على قاعدة البيانات المدمجة بـ `TEST_DB=builtin`) و `cd agent && python -m pytest` (46 اختبارًا). تعمل تلقائيًا في GitHub Actions مع كل رفع، وكل رفع إلى `main` ينشر صورة Docker جاهزة على `ghcr.io`.
