# REC Smart Audio
### نظام الإذاعة الداخلية والأذان الذكي — رسملة الطاقة للمقاولات

يشغّل **الأذان تلقائيًا** و**الإعلانات المجدولة والفورية** على سماعات ممرات المبنى، وتتحكم به من الجوال أو الكمبيوتر من داخل الشركة أو خارجها. يستمر الأذان في وقته حتى لو انقطع الإنترنت أو أُغلق المتصفح أو أُعيد تشغيل الجهاز.

---

## التشغيل في 3 خطوات

### 1) الخادم — أمر واحد
على أي خادم سحابي **Ubuntu** (مثلًا 2 vCPU و 2GB RAM):

```bash
curl -fsSL https://raw.githubusercontent.com/__REPO__/main/install.sh | sudo bash
```

يثبّت كل شيء (Docker، قاعدة البيانات، HTTPS تلقائي)، ثم يعرض لك:
- **رابط لوحة التحكم**. إن لم يكن لديك نطاق، اضغط Enter لتحصل على رابط مجاني مثل `https://203-0-113-10.sslip.io`.
- **رمز الإعداد** المطلوب في الخطوة التالية.

> المستودع خاص (Private)؟ استنسخه أولًا، ثم نفّذ `sudo ./install.sh` من داخله.

### 2) حساب المدير — من المتصفح
افتح الرابط، وأدخل **رمز الإعداد**، ثم أنشئ حساب مدير النظام. لا حاجة لأي أوامر.

### 3) جهاز السماعات — أمر واحد
في لوحة التحكم: **الأجهزة والسماعات ← إضافة جهاز**. سيظهر لك أمر جاهز يحتوي رمز الجهاز:

- **Windows:** افتح PowerShell على الجهاز الموصول بالسماعات، والصق الأمر، ووافق على نافذة صلاحيات المسؤول.
- **Linux:** الصق الأمر في الطرفية.

يثبّت الأمر Python والبرنامج، ويسجّله كخدمة تعمل تلقائيًا مع تشغيل الجهاز. بعد دقيقتين تقريبًا يظهر الجهاز «متصل». جرّب بعدها **التحكم المباشر ← اختبار السماعات**.

**التحديث لاحقًا:** نفّذ أمر الخطوة 1 مرة أخرى على الخادم. لتحديث جهاز السماعات، أعد تشغيل أمر الخطوة 3 على ذلك الجهاز.

---

## ما الذي تحصل عليه

| | |
|---|---|
| **الأذان** | أم القرى (الرياض افتراضيًا)، ملف وصوت لكل صلاة، تأخير بالدقائق، وقت ثابت، تعطيل صلاة، مطابقة التقويم الرسمي باستيراد CSV |
| **الإعلانات** | يومي / أسبوعي / مرة واحدة / نسبةً لوقت صلاة، تاريخ بداية ونهاية، إيقاف مؤقت |
| **الأولوية** | الأذان ← الطوارئ ← الإعلانات ← العامة؛ صوت واحد في كل لحظة؛ الأذان يقطع أي صوت |
| **الاستمرارية** | الجدولة تعمل محليًا على جهاز السماعات دون إنترنت، وتُعاد تلقائيًا بعد إعادة التشغيل، دون تكرار الأذان |
| **الصلاحيات** | مدير النظام، مسؤول الصوتيات، مشاهد — وسجل لكل عملية |
| **الواجهة** | عربية RTL مع الإنجليزية، ليلي ونهاري، جوال وكمبيوتر، تحديث مباشر |
| **الأمان** | HTTPS، لا منافذ مفتوحة في الداتا سنتر (الجهاز يتصل للخارج فقط)، رمز خاص لكل جهاز قابل للإلغاء |

## الربط بالسماعات
- **سلكي (موصى به):** وصّل مخرج AUX أو كرت صوت USB من الجهاز إلى مضخم سماعات الممرات.
- **بلوتوث:** أقرن السماعة من إعدادات Windows أو Linux أولًا، ثم اخترها في لوحة التحكم. لا يمكن إدارة البلوتوث من المتصفح مباشرة.

التفاصيل في [docs/AUDIO_SETUP.md](docs/AUDIO_SETUP.md).

## قبل التشغيل الفعلي
طابق أوقات الصلاة مع تقويم أم القرى الرسمي من **أوقات الصلاة ← مطابقة تقويم أم القرى**، وارفع ملفات الأذان الخاصة بالمؤسسة. القائمة كاملة في [docs/GO_LIVE.md](docs/GO_LIVE.md).

## للمطورين

| الجزء | المجلد | التقنيات |
|---|---|---|
| لوحة التحكم | [`web/`](web) | Next.js 16، TypeScript، Tailwind CSS 4 |
| الخادم | [`server/`](server) | Node.js 22، Fastify 5، Prisma 7، PostgreSQL 16، WebSocket |
| جهاز التشغيل | [`agent/`](agent) | Python 3.10+، asyncio، pygame/SDL2، SQLite، Windows Service / systemd |

```bash
# بيئة تطوير محلية (Node 22، PostgreSQL، Python 3.10+)
createuser -P rec && createdb -O rec rec_audio        # كلمة المرور: rec
cd server && cp .env.example .env && npm install && npx prisma migrate deploy && npm run dev
cd web && npm install && npm run dev                    # http://localhost:3000
# أول زيارة تطلب رمز الإعداد: تجده في سجل الخادم
```

**الاختبارات:** `cd server && npm test` (62 اختبارًا) و `cd agent && python -m pytest` (46 اختبارًا). تعمل تلقائيًا في GitHub Actions مع كل رفع، وكل رفع إلى `main` ينشر صورة Docker جاهزة على `ghcr.io`.
