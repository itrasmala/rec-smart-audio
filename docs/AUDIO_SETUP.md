# ربط السماعات بجهاز التشغيل

> **مهم:** موقع الويب لا يتحكم بالسماعات مباشرة. السماعات (سلكية أو بلوتوث) توصل **بجهاز التشغيل** في الداتا سنتر، ويقوم برنامج Audio Agent عليه بتشغيل الصوت عبر نظام التشغيل. سماعات البلوتوث العادية لا يمكن إقرانها أو إدارتها من متصفح؛ يتم الإقران مرة واحدة من إعدادات نظام التشغيل، ثم يعيد البرنامج الاتصال بها تلقائيًا قدر الإمكان.

## أي طريقة أختار؟

| الطريقة | الاعتمادية | ملاحظات |
|---|---|---|
| **AUX سلكي ← مضخم صوت/مازج نظام السماعات** | ⭐⭐⭐⭐⭐ | **الموصى بها لنظام ممرات المبنى.** لا انقطاع، لا تأخير |
| **USB Audio (كرت صوت خارجي)** ← مضخم | ⭐⭐⭐⭐⭐ | أفضل جودة من مخرج اللوحة الأم، اسم ثابت يسهل اختياره |
| HDMI (عبر Audio Extractor) | ⭐⭐⭐⭐ | إن لم يتوفر مخرج آخر |
| Bluetooth | ⭐⭐⭐ | مناسب لسماعة واحدة قريبة؛ عرضة للانقطاع والسكون التلقائي للسماعة |

نظام سماعات الممرات في المباني عادةً يُغذّى من **مضخم PA (100V line)**. وصّل مخرج الصوت من جهاز التشغيل (AUX 3.5mm أو USB DAC) إلى مدخل Line-In/AUX في المضخم.

---

## 1. الربط السلكي (AUX / USB)

### التوصيل
1. **AUX:** كابل 3.5mm (أو 3.5mm ← RCA) من مخرج السماعات الأخضر في الجهاز إلى مدخل `AUX/LINE IN` في المضخم. استخدم كابلًا مُحجّبًا، ويُفضّل **عازل حلقة أرضية (Ground Loop Isolator)** إذا ظهر طنين.
2. **USB:** وصّل كرت الصوت الخارجي ثم مخرجه إلى المضخم. أعطِ المنفذ مكانًا ثابتًا (تغيير منفذ USB قد يغيّر اسم الجهاز في Windows).
3. اضبط مستوى المضخم على مستوى آمن، واترك التحكم الدقيق للوحة التحكم (حد أقصى لكل جهاز في «الأجهزة والسماعات»).

### Windows
1. الإعدادات ← النظام ← الصوت ← المخرج: اختر الجهاز (مثل `Speakers (USB Audio Device)`) واجعله افتراضيًا.
2. عطّل «تحسينات الصوت» وأي وضع «Communications ducking»: لوحة الصوت الكلاسيكية (`mmsys.cpl`) ← الاتصالات ← «عدم القيام بأي شيء».
3. اعرض أسماء المخارج كما يراها البرنامج:
   ```powershell
   & "C:\Program Files\REC-Audio-Agent\venv\Scripts\python.exe" -m rec_agent --config "C:\ProgramData\REC-Audio-Agent\config.toml" --list-outputs
   ```
4. من لوحة التحكم: الأجهزة والسماعات ← الإعدادات ← «مخرج الصوت على الجهاز» واختر الاسم. ثم «اختبار السماعات».

### Linux (PipeWire/PulseAudio)
```bash
wpctl status                  # أو: pactl list short sinks
wpctl set-default <ID>        # اجعل المخرج المطلوب افتراضيًا
~/rec-agent/venv/bin/python -m rec_agent --config ~/rec-agent/config.toml --list-outputs
~/rec-agent/venv/bin/python -m rec_agent --config ~/rec-agent/config.toml --test-tone
```
على خادم بدون PipeWire (ALSA فقط): `aplay -l` لمعرفة البطاقات، واستخدم `alsamixer` لرفع مستوى المخرج وإلغاء كتمه (`M`) ثم `sudo alsactl store`.

## 2. الربط عبر البلوتوث

### Windows 10/11
1. شغّل السماعة في وضع الإقران.
2. الإعدادات ← Bluetooth والأجهزة ← إضافة جهاز ← Bluetooth ← اختر السماعة.
3. اجعلها مخرج الصوت الافتراضي (أو اخترها من لوحة التحكم).
4. **منع السكون:** إدارة الأجهزة ← Bluetooth ← المحوّل ← خصائص ← إدارة الطاقة ← ألغِ «السماح للكمبيوتر بإيقاف تشغيل هذا الجهاز لتوفير الطاقة».
5. **عنوان MAC:** إدارة الأجهزة ← Bluetooth ← السماعة ← خصائص ← التفاصيل ← «عنوان Bluetooth للجهاز» (أو `Get-PnpDevice -Class Bluetooth | fl FriendlyName,InstanceId`). ضعه في لوحة التحكم (الأجهزة والسماعات ← الإعدادات).
6. **حساب الخدمة:** أجهزة البلوتوث الصوتية في Windows مرتبطة بجلسة المستخدم الذي أقرنها. ثبّت الخدمة بنفس الحساب:
   `install.ps1 ... -ServiceUser ".\recaudio"` ومكّن تسجيل الدخول التلقائي لهذا الحساب إن احتجت.
7. إعادة الاتصال التلقائية على Windows تتم بتعطيل/تفعيل عقدة الجهاز (يتطلب صلاحية مسؤول). Windows لا يوفر واجهة رسمية لإجبار اتصال A2DP، لذلك هذه الآلية «أفضل جهد». إن تكرر الانقطاع فالحل الجذري هو مُستقبِل بلوتوث (Bluetooth Receiver) موصول سلكيًا، أو التحويل إلى AUX/USB.

### Linux (BlueZ + PipeWire)
```bash
sudo apt install bluez pipewire pipewire-pulse wireplumber libspa-0.2-bluetooth
bluetoothctl
  power on
  agent on
  default-agent
  scan on            # انتظر ظهور السماعة: XX:XX:XX:XX:XX:XX  اسم السماعة
  pair XX:XX:XX:XX:XX:XX
  trust XX:XX:XX:XX:XX:XX     # ← ضروري لإعادة الاتصال التلقائي
  connect XX:XX:XX:XX:XX:XX
  quit
```
- تعطيل السكون التلقائي للمحوّل: في `/etc/bluetooth/main.conf` اضبط `AutoEnable=true` و`ReconnectAttempts=7` و`ReconnectIntervals=1,2,4,8,16,32,64` ثم `sudo systemctl restart bluetooth`.
- ضع العنوان في لوحة التحكم، أو في `config.toml`:
  ```toml
  [bluetooth]
  mac = "XX:XX:XX:XX:XX:XX"
  auto_reconnect = true
  ```
- البرنامج يتحقق كل ~15 ثانية (`bluetoothctl info`) ويعيد الاتصال (`bluetoothctl connect`) عند الانقطاع، ثم يعيد فتح مخرج الصوت ويكمل الصوت الجاري من نفس الموضع.

### نصائح للبلوتوث
- كثير من السماعات **تطفئ نفسها** بعد دقائق من الصمت — عطّل خاصية Auto-off إن كانت متاحة، أو استخدم سماعة/مستقبل يعمل على الكهرباء.
- المسافة أقل من 10 م ودون جدران معدنية؛ غرف الخوادم بيئة تداخل عالية.
- تأخير البلوتوث (Latency) 100–300 ms طبيعي ولا يؤثر على الأذان.

---

## 3. التحقق
1. من لوحة التحكم: «اختبار السماعات» ← يجب أن تسمع ثلاث نغمات متصاعدة.
2. أوقات الصلاة ← «اختبار الأذان» لكل صلاة.
3. بطاقة الجهاز في «الأجهزة والسماعات» تعرض «السماعة المتصلة» و«آخر خطأ».
4. اسحب كابل الصوت أو أطفئ سماعة البلوتوث ← يظهر الخطأ في اللوحة خلال ثوانٍ، ويختفي بعد إعادة التوصيل.
