# قائمة التحقق قبل التشغيل الفعلي

## 1. التحقق من أوقات الصلاة مقابل تقويم أم القرى المعتمد ⚠️
الحساب الفلكي (أم القرى: الفجر 18.5°، العشاء = المغرب + 90 دقيقة و120 في رمضان) قد يختلف دقيقة أو دقيقتين عن التقويم الرسمي المنشور بسبب التقريب والاحتياط المعتمد. **لا تعتمد الأوقات قبل مطابقتها:**

1. احصل على تقويم أم القرى الرسمي لمدينة الرياض (الشهر الحالي والقادم على الأقل).
2. حوّله إلى CSV بالصيغة: `2026-10-25,04:37,11:37,14:52,17:18,18:48` (تاريخ، فجر، ظهر، عصر، مغرب، عشاء) بنظام 24 ساعة.
3. لوحة التحكم ← **أوقات الصلاة ← مطابقة تقويم أم القرى** ← الصق/اختر الملف ← **مقارنة بالأوقات المحسوبة**.
4. راجع «أكبر فرق». إن كان 0–1 دقيقة يمكنك الاعتماد على الحساب. إن وُجد فرق:
   - فرق ثابت لصلاة معينة (مثلًا الظهر دائمًا +2) ⇐ استخدم **تأخير بالدقائق** لتلك الصلاة.
   - فروق متفرقة ⇐ اضغط **اعتماد هذه الأوقات** فتُحفظ كتعديلات لكل تاريخ (لها الأولوية على الحساب) وتُرسل للأجهزة فورًا.
5. كرّر الاستيراد كل شهر أو استورد السنة كاملة دفعة واحدة.

> مرجع التحقق المضمَّن في الاختبارات: جدول الرياض لشهر أكتوبر 2026 بطريقة أم القرى (تطابق ±1 دقيقة)، وتطابق 100% بين حساب الخادم وحساب الجهاز لمدة 730 يومًا (2026–2027) بما فيها رمضان.

## 2. الجهاز والسماعات
- [ ] الجهاز يظهر «متصل» في الأجهزة والسماعات، و«خطة الأذان المخزنة حتى» بعد شهرين تقريبًا.
- [ ] «الملفات المخزنة محليًا» بلا ملفات ناقصة.
- [ ] «اختبار السماعات» مسموع في كل الممرات.
- [ ] «اختبار الأذان» لكل صلاة بمستوى صوت مناسب (لا يُحتسب كأذان فعلي).
- [ ] ساعة الجهاز مضبوطة (لا يظهر تحذير فرق الساعة).
- [ ] الحد الأقصى لمستوى الصوت مضبوط للجهاز.

## 3. الاستمرارية (جرّبها فعليًا)
- [ ] افصل كابل الشبكة عن جهاز التشغيل قبل أذان بدقيقتين ⇐ يُرفع الأذان في وقته، وعند إعادة الكابل يظهر في السجل مع أيقونة «نُفّذ دون اتصال».
- [ ] أعد تشغيل جهاز التشغيل ⇐ تبدأ الخدمة تلقائيًا ويعود «متصل» دون تسجيل دخول.
- [ ] أغلق المتصفح أثناء تشغيل إعلان ⇐ يستمر الإعلان.
- [ ] شغّل إعلانًا قبل الأذان بدقيقة ⇐ يُقطع عند دخول الوقت ويبدأ الأذان.

## 4. الحسابات
- [ ] غيّرت كلمة مرور مدير النظام، وأنشأت حسابات شخصية لكل مستخدم بالدور المناسب.
- [ ] راجعت إعدادات: سلوك ما بعد الأذان، فترة الهدوء، سياسة الطوارئ، الحد الأقصى لمسؤول الصوتيات.
