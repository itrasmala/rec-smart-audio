# الاختبارات

| المجموعة | الأمر | العدد |
|---|---|---|
| الخادم: وحدات + API + WebSocket + الإعداد الأول + حزمة التثبيت (PostgreSQL حقيقي) | `cd server && npm test` | 62 |
| جهاز التشغيل: الطابور، الجدولة، الأذان، الانقطاع | `cd agent && python -m pytest` | 46 |
| تكامل حي (خادم + جهاز حقيقي + قطع الشبكة) | `cd agent && REC_E2E_PASSWORD=... python -m pytest -m e2e tests/e2e -s` | 1 سيناريو |

اختبارات الخادم تستخدم قاعدة `rec_test` (تُعاد تهيئتها من ملفات الترحيل في كل تشغيل) — أنشئها مرة: `createdb -O rec rec_test`، أو اضبط `TEST_DATABASE_URL`.

تعمل كلها تلقائيًا في **GitHub Actions** (`.github/workflows/ci.yml`) مع كل رفع: الخادم على Linux، وجهاز التشغيل على **Linux و Windows**، وبناء لوحة التحكم، وفحص سكربتات التثبيت (PowerShell + shellcheck).

## ما الذي تغطيه

### الأذان وأوقات الصلاة
- مطابقة جدول الرياض المنشور بطريقة أم القرى (أكتوبر 2026) بفارق ≤ 1 دقيقة — في الخادم والجهاز.
- **تطابق تام (0 ثانية) بين حساب الخادم (adhan-js) وحساب الجهاز الاحتياطي (Python) لـ 730 يومًا** — كشف هذا الاختبار خطأ تقريب في مكتبة adhanpy (09:00 تصبح 08:59 عند الدقيقة 59) وتم تصحيحه.
- العشاء = المغرب + 120 دقيقة في رمضان و90 خارجه.
- الأولوية: تعديل التاريخ > الوقت الثابت > الحساب، مع الإزاحة.
- الأذان يبدأ خلال ≤ 1 ثانية من دخول الوقت، **ومرة واحدة فقط**.
- لا تكرار بعد إعادة تشغيل الجهاز (عملية جديدة، نفس قاعدة SQLite).
- التعويض: عودة الجهاز خلال 3 دقائق ⇐ يُشغَّل؛ بعد ذلك ⇐ «لم يُشغَّل» دون تشغيل متأخر.
- أحداث أُضيفت بعد وقتها لا تُسجَّل خطأً كـ «فائتة» بعد إعادة التشغيل.
- صلاة معطّلة لا تُشغَّل؛ صلاة بدون ملف ⇐ «فشل» واضح.
- حساب محلي تلقائي عند تجاوز الخطة المخزنة (انقطاع طويل).

### أولوية التشغيل
- الأذان يقطع الصوت العام ⇐ تجاهل / استئناف من نفس الموضع / إعادة من البداية حسب الإعداد.
- الإعلان يقطع العام ثم يُستأنف العام.
- لا تداخل: عنصران من نفس الأولوية ⇐ الثاني ينتظر (تحقق أنه لا يوجد تشغيلان مفتوحان في أي لحظة).
- الطوارئ تنتظر الأذان وتتقدم على الإعلانات في الطابور؛ لا تقطع الأذان إلا بسياسة مفعّلة **و** طلب صريح.
- الأذان محمي من الإيقاف والإيقاف المؤقت لغير مدير النظام.
- انتهاء صلاحية العناصر المنتظرة، فترة الهدوء بعد الأذان، حدود مستوى الصوت.
- مثال المستخدم كاملًا: 7:00 ترحيب، 12:00 إعلان إداري، الأذان يقطعه، 16:00 نهاية الدوام.

### الخادم والأمان
- رفض غير المسجلين، كوكي HttpOnly + SameSite=Strict، الخروج يُبطل الجلسة على الخادم.
- قفل الحساب بعد 5 محاولات، رفض الطلبات من Origin خارجي.
- صلاحيات الأدوار الثلاثة على كل المسارات، منع حذف آخر مدير نظام.
- رفع MP3/WAV حقيقي وقياس المدة، رفض ملف مزيف بامتداد mp3، Range streaming.
- منع حذف ملف مستخدم في الأذان/الجداول.
- رمز الجهاز يظهر مرة واحدة، الرمز الخاطئ يُرفض **قبل** فتح WebSocket، الإلغاء يقطع الاتصال فورًا ويمنع العودة، التدوير يُبطل القديم.
- دورة الأمر كاملة: اللوحة ← الخادم ← الجهاز ← تأكيد، مع تقييد الصوت لحد الدور.
- أمر لجهاز منقطع ينتظر ويُسلَّم عند العودة ضمن المهلة.
- السجلات المكررة بعد الانقطاع تُدمج (سجل واحد بالحالة النهائية).
- دفع الإعدادات تلقائيًا للجهاز عند أي تعديل.
